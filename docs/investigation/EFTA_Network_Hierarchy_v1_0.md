## How to read this

This is a **functional** hierarchy — it maps how the machine worked, not how guilty anyone is. Evidence tier is carried as a badge on every name so the two questions never collapse into each other.

The **Clients & Alleged Abusers** branch is deliberately parallel and non-reporting. Those people did not run the operation and the operation did not report to them. Rendering them as a chain of command would be false.

**Victims are a separate branch entirely.** Three people appear in both the victim branch and an operator role; each is flagged, because coerced recruitment is itself a product of trafficking and reading those entries as ordinary complicity would be a serious misreading.
